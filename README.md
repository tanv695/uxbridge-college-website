# Uxbridge College Website

A responsive, static multi-page college website built with HTML, CSS and JavaScript.

## Pages
- `index.html` — home
- `about.html` — about the college
- `courses.html` — study pathways
- `student-life.html` — student experience and support
- `admissions.html` — application guidance
- `news.html` — news and updates
- `contact.html` — contact details and enquiry form

## Run locally
Open `index.html` in a browser, or start a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing
This is a front-end demonstration. Verify the college’s official contact details, course information, and admissions process before publishing. Replace sample news and imagery with approved, current content. The contact form uses a `mailto:` link and does not send data to a server.
