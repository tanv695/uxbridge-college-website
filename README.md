# Uxbridge College Website

This is a responsive static website for Uxbridge College built with HTML, CSS and a small JavaScript enhancement.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – page structure and content
- `styles.css` – styling and layout
- `script.js` – mobile menu and form interaction

## Overview

The site includes:
- a hero section with call-to-action buttons
- course categories and student experience sections
- admissions steps
- latest news cards
- contact form and footer
- responsive design for mobile devices
